Forecast the next gameweek. Respect the clock.

A reproducible FPL pipeline that rejects empty future placeholders, builds only as-of features, and compares regression with honest recent-form baselines in time order.

Read the guideInspect the protocol

Designed around evidence quality

The difficult part is not fitting a regressor. It is proving that every input existed before the outcome and that every reported prediction came from a later gameweek.

1

Strict inputs

Empty, duplicate, gapped, malformed, and low-coverage gameweeks fail before feature construction.

2

As-of features

Latest form, rolling windows, and season totals stop at gameweek t; the target comes from completed t+1.

3

Future-only tests

Expanding train windows predict later, non-overlapping gameweeks and retain row-level out-of-fold evidence.

End-to-end flow

One CLI covers deterministic examples, validation, table construction, evaluation, reporting, and a safe final artifact.

InputCompleted live-gameweek JSON
GateSequence and coverage validation
BuildFixed as-of feature contract
EvaluateRolling baselines and ridge
DeliverJSON, CSV, and local HTML

Leak controls

  • No empty future gameweek becomes a zero label
  • No player absence is silently converted to zero
  • No identifier or target enters the feature matrix
  • No test gameweek precedes training data
  • No executable pickle artifact is loaded

What ships

Focused tests cover the data contract, future-invariance, boundary guards, chronological splits, ranking metrics, end-to-end evaluation, CLI flow, and artifact round trips.

No live data or model claim ships. Run fpl-forecast synthetic for a deterministic example, then replace it with separately obtained completed-gameweek files.

The generated report is a single local HTML file with no external scripts, fonts, trackers, or network calls.
